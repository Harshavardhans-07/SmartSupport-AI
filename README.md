
# 🤖 SmartSupport AI

### AI Customer Support Assistant with Long-Term Memory

## 📌 About the Project

SmartSupport AI is an intelligent customer support chatbot
that uses AI and long-term memory to provide personalized
customer support.

It remembers useful customer information and preferences
to improve future conversations.

## 🚀 Features

- AI-powered customer support chatbot
- Groq LLM integration
- Hindsight long-term memory
- Customer memory retrieval
- Automatic customer profile extraction
- Streamlit dashboard

## 🛠️ Technologies Used

- Python
- Streamlit
- Groq API
- Hindsight AI
- SQLite (if enabled in your project)

## ⚙️ Installation

1. Clone the repository.

2. Install dependencies:

   pip install -r requirements.txt

3. Create a `.env` file and configure your API keys.

4. Run the application:

   streamlit run app.py

## 💡 How It Works

1. Customer enters a question.
2. Groq generates an AI response.
3. Hindsight retrieves relevant customer memories.
4. Customer information is displayed in the dashboard.
